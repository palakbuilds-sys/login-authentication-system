# Login Authentication System 🔐

A secure user authentication system built using Node.js, Express.js and bcrypt.

## Features

- User registration
- User login
- Password hashing using bcrypt
- Session-based authentication
- Protected dashboard
- Logout functionality
- Duplicate email detection
- Invalid login handling
- Environment variables for session secrets

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Express Session
- bcryptjs
- dotenv
- JSON file storage
